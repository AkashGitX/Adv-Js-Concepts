# JavaScript DOM & Advanced JavaScript Concepts

This repository contains my JavaScript practice and learning work, focused mainly on **DOM Manipulation, Events, Promises, Fetch API, and other Advanced JavaScript concepts**.

The purpose of this repository is to build a strong foundation in JavaScript before moving further into frameworks like React.

---

## 📚 Topics Covered

### DOM (Document Object Model)

- DOM Selection
- Creating HTML elements using JavaScript
- Adding elements to the DOM
- Editing DOM elements
- Removing DOM elements
- Changing text and HTML
- Working with attributes
- DOM properties and methods

### JavaScript Events

- Event handling
- `click` events
- Event listeners
- Event objects
- Start / Stop functionality
- Different types of browser events

### Promises

- Creating Promises
- `resolve()`
- `reject()`
- `.then()`
- `.catch()`
- Promise chaining
- Handling asynchronous operations

### Async JavaScript

- `async` / `await`
- Asynchronous functions
- Handling asynchronous operations
- Working with API requests

### Fetch API

- Making API requests using `fetch()`
- Handling HTTP responses
- Converting responses using `response.json()`
- Working with API data
- Displaying fetched data

### JavaScript Fundamentals

- Functions
- Arrow functions
- Arrays
- Objects
- Array methods
- Variables
- Callbacks
- Higher-order functions
